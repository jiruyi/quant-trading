# Phase 1 Roadmap

1. Market data collectors: daily bars, limit-up pool, dragon-tiger list, block trades.
2. Theme engine: rank active themes by limit-up count, net flow, continuity, and height.
3. Emotion engine: classify market state as ice, repair, main-rise, climax, or ebb.
4. MonsterScore: combine capital, emotion, pattern, and chip factors into a 0-100 score.
5. TOP10 pool: output highest-ranked candidates with reasons and risk notes.
6. Daily review: generate a Markdown report for next-day preparation.
